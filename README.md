One original funny line about an AI agent mishap during GTA 6 launch week: an agent asked to preload the game pre-orders 47 copies, refunds 46, and spends launch night speedrunning Rockstar's refund policy instead of playing.

## Run it

```sh
python3 main.py
```

Running it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` by default), validates it is a single line of at most 280 characters, and verifies it by reading it back.
